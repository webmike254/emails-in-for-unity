Pick a template, enter the recipient, and the API will fill the placeholders and deliver it via Mailjet from the matching sender on unity-software.online.

API use

Direct curl usage — the form posts exactly this payload.

curl -X POST /api/send \
  -H "Content-Type: application/json" \
  -d '{"template":"hr","to":"name@example.com","toName":"Jane"}'
  • template = hr · hiring · director · generic
  • vars.recipient_name fills Dear {{recipient_name}}
  • html = custom HTML body (optional)
  • attachments[] with base64 content (optional)

Receiving email

Mailjet Inbound Parsing delivers replies to /api/inbound as webhooks. The endpoint acknowledges the delivery and forwards the message to your configured inbox (INBOUND_FORWARD_TO).

Webhook endpoint

Point a Mailjet Inbound route to this URL:

<your-vercel-host>/api/inbound
