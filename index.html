How to use with MailerSend

  1. Upload the three HTML files and the assets (header.jpg, avatar_*.png) to a public location or host them on your domain.
  2. In MailerSend, create a template (or send raw HTML) and paste the content. Replace {{recipient_name}} with the actual name or use MailerSend personalization variables.
  3. Set the From address to the matching role (these are already under your verified domain):
hr@unity-software.online — Amara Njoroge, HR Manager
hiring@unity-software.online — Daniel Ochieng, Hiring Manager
director@unity-software.online — Grace Wambui, Director
hello@unity-software.online — general / fallback

No extra domain verification is required. Any address on unity-software.online can be used as the From address once the domain is verified.
