API use

Template (left) or custom body (right) — both post the same /api/send.

curl -X POST /api/send \
  -H "Content-Type: application/json" \
  -d '{"template":"hr","to":"name@example.com","toName":"Jane"}'

# custom:
-d '{"to":"jane@x.com","subject":"Hello",
     "body":"Your own message here\\nSecond paragraph",
     "identity":"hr"}'
  • template = hr · hiring · director · generic · custom
  • body = your own plain-text message (custom)
  • identity = hr · hiring · director · hello (sender + signature)
  • html = exact HTML (optional) · attachments[] base64 (optional)

Receiving email

Mailjet Inbound Parsing delivers replies to /api/inbound as webhooks. The endpoint acknowledges the delivery and forwards the message to your configured inbox (INBOUND_FORWARD_TO).

Webhook endpoint

Point a Mailjet Inbound route to this URL:

<your-vercel-host>/api/inbound
